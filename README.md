# Online CV

This repository is set up as a simple, responsive online CV that can be hosted with GitHub Pages. The site is `index.html` and does not require a build step.

## Personalize it

Edit `index.html` and replace the example content with your own:

- Name, professional title, and short introduction
- Contact details and professional profile links
- Experience, education, skills, and selected projects
- Page title and description in the `<head>`

Remove any sections that do not apply. Avoid publishing private information such as your home address or personal phone number unless you intend it to be public.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then save.
4. After the deployment completes, the Pages settings page will show the public site URL.

Changes committed to `main` will be published automatically. You can also print the page or use your browser's **Print → Save as PDF** option to make a PDF CV.
